# Stl and FreeCAD files for the fiber spectrometer

I used GaudiLabs spectrometer as based and adjusted some parameters for a
slightly different camera. Feel free to modify it as you see fit.


# WARNING

The FreeCAD and .stl files are scaled 10x from the actual size! This is due to
my lack of CAD skills. When printing, scale the model down 10x! Also, when
editing the FreeCAD file, 10mm is in actuality 1mm due to scale. Sorry about
that.

## Components

You can use this page from GaudiLabs as reference: https://www.gaudi.ch/GaudiLabs/?page_id=1124

You will need:

1. Optical Fiber cable. You can buy any standard audio cable.
2. A specific very small camera. You can get one on Amazon for
   10$. Search for "Mini USB2.0 Webcam Board". 
3. Small (any color, but preferably white) LED
4. Cuvettes for liquids. These are also easy to find online.
5. Access to 3D printer, either at home, or online services.
